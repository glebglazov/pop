# Drains share a per-project `pop-work` window

> **Tombstoned.** [ADR-0180](0180-task-set-panes-live-in-their-bound-checkouts-session.md) supersedes this whole: a Task set's panes live in the session of the checkout the set is bound to, which is the session-per-worktree-set option this ADR rejected. The `pop-work` window itself survives unchanged and is restated there — one window per session, panes tiled, one pane per (set, verb) — so nothing here still describes current behaviour.
